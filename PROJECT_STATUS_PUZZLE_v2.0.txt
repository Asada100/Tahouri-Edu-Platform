IMPORTANT DESIGN NOTE
========================================

The Puzzle architecture is technically operational.

However, some puzzle types are not yet sufficiently clear
from a student's educational/UX perspective.

Especially:

- Grid
- Word Grid
- Cross Math

Cross Math requires a later dedicated UX/design pass.

Current Cross Math concept:

- Horizontal paths
- Vertical paths
- Operations
- Multiple cells
- Missing cells
- Mathematical relationships

The final Cross Math design should be based on a clearer
educational model and later visual examples.

Do NOT redesign the Puzzle architecture in the next stage
unless a real technical problem is found.
