# پنل مدیریت سرویس مجوز طهوری

## نشانی پنل

پنل از خودِ سرور Node.js سرویس مجوز ارائه می‌شود؛ فایل‌های آن به‌تنهایی روی GitHub Pages یا Cloudflare Pages قابل استفاده نیستند.

پس از اجرای سرویس روی یک میزبان واقعی، نشانی پنل این است:

`https://<API-DOMAIN>/admin`

در اجرای محلی، اگر سرویس روی پورت پیش‌فرض باشد:

`http://127.0.0.1:8787/admin`

## پیش‌نیازهای اجرا

- سرویس `services/license-api/server.js` باید روی یک میزبان دارای Node.js و SQLite اجرا شود.
- مسیر پایگاه داده و پوشهٔ پشتیبان باید روی فضای پایدار میزبان تنظیم شوند؛ فایل‌های موقت یا دیسک موقتی میزبان برای نگهداری دائمی مناسب نیستند.
- متغیرهای `TAHOURI_ADMIN_PASSWORD`، `TAHOURI_ADMIN_ORIGIN`، `TAHOURI_APP_ORIGIN` و `TAHOURI_LICENSE_PRIVATE_KEY_FILE` باید در تنظیمات محرمانهٔ میزبان تعریف شوند. رمز مدیر باید قوی و یکتا باشد.
- برای اجرای تولیدی، بررسی پیش‌راه‌اندازی سرویس را هم انجام دهید؛ تنظیمات درگاه پرداخت واقعی و کلیدهای امضای مجوز و پشتیبان نیز الزامی‌اند.
- برای پشتیبان‌گیری خارج از میزبان، مقصد SSH مستقل و متغیرهای `TAHOURI_BACKUP_OFFSITE_*` باید واقعاً پیکربندی شوند. آزمون محلی با `fake scp` اثبات اتصال به مقصد واقعی نیست.

## مسیر انتشار

1. یک میزبان سازگار با Node.js و ذخیره‌سازی پایدار SQLite انتخاب کنید.
2. سرویس `services/license-api` را با متغیرهای محرمانه در محیط میزبان مستقر کنید؛ فایل کلید خصوصی و رمزها را داخل Git یا پوشهٔ عمومی وب قرار ندهید.
3. `/api/health` را بررسی کنید و سپس `/admin` را باز کنید.
4. ورود مدیر و عملیات پنل را روی همان مبدأ HTTPS آزمایش کنید.
5. پشتیبان‌گیری واقعی به مقصد مستقل و بازیابی از همان مقصد را جداگانه آزمایش کنید.

## نکتهٔ امنیتی

تا وقتی میزبان واقعی، تنظیمات محرمانه و مقصد مستقل پشتیبان‌گیری فراهم و آزمایش نشده‌اند، نشانی عمومیِ فعال یا آمادگی تولیدی را اعلام نکنید. این فایل راهنمای انتشار است و به‌خودی‌خود سرویس را منتشر نمی‌کند.
